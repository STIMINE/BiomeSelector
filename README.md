# Biome Selector (Forge 1.7.10)

`Biome Wand` を使って、選んだ矩形範囲のバイオームを書き換える MOD です。

Minecraft Forge **1.7.10-10.13.4.1614** 向けです。対応する Minecraft のバージョンは **1.7.10**、MOD のバージョンは **1.3.0** です。

## 導入方法

1. Minecraft 1.7.10 に Forge `10.13.4.1614` を導入します。
2. 配布された `BiomeSelector-1.3.0.jar` を、クライアントまたはサーバーの `mods` フォルダーへ入れます。
3. シングルプレイでは、Forge 導入済みクライアントの `mods` フォルダーへ入れるだけで利用できます。マルチプレイでは、サーバーと参加するクライアントの両方に同じ JAR を入れてください。

> この MOD はゲーム内のチャンク情報を書き換えます。大切なワールドは、作業前に必ずバックアップしてください。

## 使い方

1. クリエイティブタブ **Tools** から `Biome Wand` を入手します。
2. 杖を持ってブロックを右クリックし、1 点目を選択します。
3. 別のブロックを右クリックし、2 点目を選択します。高さは無関係で、X/Z の矩形が対象です。
4. 杖を持ったまま、何もない空中を右クリックします。
5. 一覧からバイオームを選び、**変更する** を押します。

選択はプレイヤーごと・ディメンションごとに保持されます。黄色の表示が 1 点目、緑色の線が確定した範囲です。バイオーム変更が完了すると、範囲の線は消えます。

### 処理の停止

実行中に `Biome Wand` を持って **Shift + 空中右クリック** すると、自分が開始した未完了の変更処理を停止できます。途中まで変更済みの部分は元に戻らないため、必要に応じて改めて範囲指定して変更してください。

### 大きな範囲について

既定の最大範囲は **1000×1000 ブロック** です。処理は一度に全範囲を書き換えるのではなく、毎ティック指定数のチャンクずつ処理します。そのため、遠方チャンクが未読み込みでも対象に含められ、急なフリーズを抑えます。

ただし、巨大範囲では処理時間やワールド保存の負荷が増えます。サーバーでは人数や他 MOD の負荷を考慮して、後述の `ChunksPerTick` を小さめに設定してください。

## 設定

初回起動後に `config/biomeselector.cfg` が生成されます。変更後はゲーム／サーバーを再起動してください。

|項目|既定値|説明|
|---|---:|---|
|`MaxAreaBlocks`|`1000000`|1 回の変更を許可する最大ブロック面積。既定値は 1000×1000。|
|`ChunksPerTick`|`8`|毎ティックに変更するチャンク数。小さいほど負荷は下がりますが、完了まで長くなります。|

## ビルド

このプロジェクトには Java 8 と Gradle 2.14.1 を固定して起動する `gradle-1.7.10.cmd` が含まれます。次を実行してください。

```powershell
.\gradle-1.7.10.cmd build
```

生成物は `build/libs/BiomeSelector-1.3.0.jar` です。
